# Research Copilot 本地审查修复（2026-10-13）

基线：用户上传压缩包，源码与 `research-copilot` 分支 `e96cf780` 的114个跟踪文件一致。
本次修改目标是修复可信度与执行器缺陷；未进行修复后的真实模型能力评测，也未推送远端。

## 已完成

1. **证据门禁**：lookup 绑定字段路径，禁止用样本量匹配均值；缺数据、未支持的检查、
   无结构化关系、无显著性依据都不能自动升级；非有限数值拒绝；关系引用失效不能偷换
   到别的观测；受控实验缺干预变量关联仍降级。方向断言保留字符串，不再转换成 NaN。
2. **已证实陈述的范围**：只把确定性观测或通过结构化检查的程序生成事实写入结果，
   原始自由文本保存在 `validation.draft_statement`。通过数值检查不证明整段自由解释正确，
   不证明统计方法适用，更不证明因果关系成立。多表数值分析必须显式绑定相对文件名。
3. **统计与报告**：得分区间限 [0,1]，配对差限 [-1,1]，负区间不再被截掉；主表显示
   全任务得分的聚类区间；完成但评分失败不记成模型 0 分；缺任务/评分时不发布完整配对差。
4. **任务工作区**：每个任务保留工作目录到 close；数据快照仍文件级只读绑定；支持
   子目录及 /opt/virtualenv Python；只挂用户 site-packages，不再回退挂整个 ~/.local。
   超时及任务结束清理进程组，输出写临时文件并有资源限额，不依赖子进程主动关闭管道。
5. **协议与轨迹**：单 JSON 对象正确处理嵌套大括号；多动作响应拒绝并反馈协议错误；
   DSML 参数只在单个完整调用内提取；请求、完整响应、实际工具结果及隔离记录都归档。
   同时报告解析失败、工具失败和预算耗尽，不把终态标签当作确定根因。异常路径保留成本。
6. **自动测试**：实际探测 bwrap 启动能力；隔离集成未运行时明确跳过；可通过
   `RC_REQUIRE_SANDBOX=1` 要求该门禁必过。CI 生成证据与 JUnit artifact，不再向工作分支
   自动提交；通过数不包含跳过数；证据绑定被测源文件哈希，并在失败时保留。

## 本地使用

```bash
pip install -e '.[dev,eval]'
PYTHONPATH=src python -m pytest -q --junitxml=test-results/junit.xml
python scripts/write_test_evidence.py --junit test-results/junit.xml
PYTHONPATH=src python scripts/reanalyze_archived_runs.py --source eval-runs --out docs/reanalysis/latest
```

真实模型新评测需要可运行的 bwrap 和配置好的模型端点，先确认基础执行与环境无误，
再在新任务上比较原预算与增加预算，按同模型、同任务与同工具限额报告结果。
