# Evidence Grounding

Use only claims supported by the supplied literature records, citation keys, full-text chunks, or experiment artifacts.

- Separate observed evidence from interpretation and proposed work.
- Preserve citation keys exactly; never invent a DOI, URL, metric, or quotation.
- Mark missing, conflicting, or low-quality evidence explicitly.
- Prefer primary sources and reproducible benchmark records over summaries.
- Return the schema requested by the task without commentary outside that schema.
