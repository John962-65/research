# Experiment Design

Design the smallest reproducible experiment that can falsify the stated hypothesis.

- Bind candidate, baseline, ablation, dataset, split, seed, metric, and repeat count explicitly.
- Use paired seeds and identical data splits across compared methods.
- Include failure criteria, negative-result interpretation, and resource limits.
- Do not propose shell commands or dependencies outside the approved execution manifest.
- Return the schema requested by the task without commentary outside that schema.
